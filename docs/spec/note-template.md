> 앱 쪽 입구(연결 화면의 `저장소 만들기` · 목록 없음 상자의 길 · 템플릿 주소 값)는 `docs/spec/repo-connect.md` 의 RC-25 · RC-26 · RC-9 가 맡는다. 이 문서는 **앱 밖** — 템플릿 저장소 · Action · 규격 · 플러그인 — 만 쓴다.
> 이 레포(`KimHance/MyNote`)는 **비공개**다(무인증 저장소 조회가 404). 그래서 남이 쓰는 것은 모두 공개 레포에 있어야 하고, 이 레포는 **그 공개 레포들의 원본**을 `public-repos/` 에 둔다. 실제 GitHub 공개 · 레포 이름 · 템플릿 지정은 사람이 한다(결정 2).
> 화면 이름은 `저장소 만들기`(입구 버튼) · `형식 안내 보기`(목록 없음 상자의 둘째 길)이고 문구 원본은 디자인 문서 문구표다. 옛 작업 이름 `새로 만들기` · `템플릿 보기` 는 쓰지 않는다.

## 기획

### 왜

앱은 이제 링크를 붙여 노트 저장소를 연결한다(`repo-connect`). 그런데 **노트 저장소가 아직 없는 사람**에게는 갈 곳이 없다. 노트 형식(블록 JSON + `notes/index.json` + sha256)은 이 레포의 한국어 내부 문서(`notes/SCHEMA.md`)와 로컬 스크립트(`notes/gen_index.py`)와 커밋 훅에만 있고, 훅은 파이썬과 `git config` 가 있는 기기에서만 돈다. "저장소를 만들어서 앱에 붙이세요" 는 안내가 아니라 숙제다.
시작하는 사람이 **템플릿으로 저장소 하나를 만들고 주소를 앱에 붙이면 곧바로 예시 노트가 보이고**, 그 뒤 노트를 올릴 때 `index.json` · 해시 · 형식 검사를 **GitHub 가 대신** 하게 해야 한다. 스킬(Claude Code 플러그인)은 있으면 편한 덤이지, 없어도 규격 + Action 만으로 쓸 수 있어야 한다.
2026-10-07 에 이 레포 노트와 앱이 마크다운(`.md` — 앞머리 `title` · `date` + GFM)으로 옮겨 갔는데(`note-format`) 공개 원본은 JSON 그대로였다. 공개 도구는 `.json` 만 훑어서 템플릿으로 만든 저장소에 `.md` 노트를 올리면 **목록에 안 실리고 앱에 안 보인다**. 템플릿 · 도구 · 규격 · 스킬이 이 레포와 같은 마크다운 노트를 쓰고, 같은 노트에서 같은 목록을 내야 한다(결정 19).

### 누구

| 누가 | 언제 쓰나 |
|---|---|
| 앱을 처음 깐 사람(저장소 없음) | 앱의 `저장소 만들기` 로 템플릿을 받아 자기 저장소를 만들 때 |
| 노트를 쓰는 사람 | 웹 편집기 · 로컬 편집 · 플러그인 스킬로 노트를 올릴 때 |
| 도구를 고치는 사람(이 레포 작업자) | 형식 · 검사기 · Action · 스킬을 고치고 공개 원본을 맞출 때 |
| 규격을 읽는 사람 | 다른 도구(자기 스크립트 · 다른 에이전트)로 노트를 만들 때 |

### 흐름

1. 앱 연결 화면의 `저장소 만들기` → 외부 브라우저에서 GitHub 템플릿 생성 화면 → 저장소 이름 · 공개 여부를 정하고 만든다.
2. 새 저장소는 예시 노트와 이미 만들어진 `notes/index.json` 을 들고 있다. 저장소 주소를 복사해 앱의 `저장소 주소` 칸에 붙이고 `연결` → 예시 노트가 홈에 보인다.
3. 노트를 올린다 — GitHub 웹에서 파일 추가 · 로컬 clone 에서 편집 · 플러그인 스킬 중 어느 길이든 `notes/<그룹>/<id>.md`(앞머리 + 마크다운) 만 커밋한다. 옛 `notes/<그룹>/<id>.json` 도 읽힌다(결정 19).
4. push 되면 저장소의 workflow 가 저장소 안의 도구(`tools/note_tool.py`)를 실행해 모든 노트를 검사하고 `notes/index.json` 을 다시 만들어 같은 브랜치에 올린다. 검사에서 걸리면 `index.json` 은 그대로이고 작업 실패가 어느 파일 · 왜인지 말한다.
5. 앱에서 새로고침 → 새 노트가 보인다.
6. 공개 뒤 형식이 올라가면 템플릿의 도구 · 규격 사본이 새 판으로 바뀌고, 이미 만든 저장소는 그 두 파일을 덮어쓴다(결정 31). 공개 전에 올라간 형식은 첫 공개 판이 그대로 담는다(결정 20).
