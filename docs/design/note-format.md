## 폭

| 이름 | 값 | 바뀌는 것 |
|---|---|---|
| compact | 360 · 본문 328 · 1em 16 | 기본 — 넓은 표는 가로 스크롤, 줄바꿈 표는 본문 폭에 꼭 맞는다 |
| Fold 패널 펼침 | 852 · 본문 488 | 줄바꿈 열이 칸 최대 폭에서 멈추고 표가 본문보다 좁아진다 |
| Fold 패널 접음 | 852 · 본문 656 | 시안 없음 — 규칙이 같고 자리만 넓다(넓은 표 예시 525 는 스크롤 없이 들어간다) |
| 큰 글자 | 360 · 1em 23.4(18 × 시스템 1.3) | em 값이 같이 커진다 — 좁은 표도 스크롤 · 들여쓰기 멈춤이 먼저 보인다 |

**1em = 그 자리 본문 글자 크기**(크게 · 시스템 배율을 곱한 값). 들여쓰기 · 기호 칸 · 상자 · 열 폭은 em, 선 · 여백 · 페이드는 dp.

## 모양

### 글자 모양 (NF-4)

| 모양 | 그리는 법 |
|---|---|
| 기울임 | 모양만 기울인다 — 색 · 굵기는 둘레 그대로 |
| 인용 안 기울임 | **바로 세운다**(결정 13) — 인용 블록이 이미 기울임이다 |
| 취소선 | 가운데 줄 · 줄 색 = 그 구간 글자 색 · 흐리게 하지 않는다(`text3` 는 뜻을 지는 글자 금지 — DESIGN §10.2) |
| 겹침 | 굵게(700 `text`) · 기울임 · 취소선을 그대로 합친다 |
| 코드 구간 | 코드 모양만 — 굵게 · 기울임은 안 붙는다. **취소선만 긋는다**(결정 14), 줄 색 `accent` |
| 자리 | 문단 · 제목 · 목록 · 인용 · 표 칸에서 같은 규칙 |

### 목록 (NF-6)

| 무엇 | 값 |
|---|---|
| 기호 칸 | 목록마다 하나 — 폭 = 그 목록에서 가장 넓은 기호(`•  ` ≈ 0.875em · `10. ` ≈ 1.62em · 상자 칸 1.625em). 번호는 칸 안 끝 맞춤(점이 한 세로선), 글머리 · 상자는 시작 맞춤. 색 `text2` |
| 하위 블록 | 부모 항목 글 시작선(= 부모 기호 칸 끝)에서 시작. 항목 글 ↔ 하위 블록 · 하위 블록끼리 6(항목 사이와 같다) |
| 들여쓰기 한도 | **3단에서 멈춘다** — 4단부터 3단과 같은 x(결정 11). 하위 코드 · 표는 남은 폭에서 자기 규칙(가로 스크롤) |
| 글머리 | 실제 깊이로 돈다 — 1 `•` · 2 `◦` · 3 `▪` · 4 `•` … 멈춘 단도 기호는 바뀌어 단이 구별된다. 번호 목록은 모든 단 숫자 |
| 시작 번호 | 지킨다. 한 자리 번호만인 목록 · 1단 `•` 는 지금 모양 그대로(`## 제약` 바뀌면 안 됨) |
| 체크 상자 | 새 아이콘 둘 — 끔 = 선 상자 · 켬 = 채운 상자(안의 체크 모양은 비워 바탕이 보인다). MyNoteIcons 규격: 24 뷰포트 · 상자 3–21 · 반경 4 · 선 1.7. 표시 1.25em · 상자 칸 1.625em · 첫 줄 높이 가운데 · 켬 · 끔 모두 `text2` · 항목 글은 그대로(흐림 · 줄 없음) |
| 섞인 목록 | 체크 항목과 일반 항목이 섞이면 기호 칸 = 상자 칸, `•` 는 칸 시작 |
| 번호 + 체크 | 번호 칸 뒤에 상자 칸 — 번호(순서)를 지우지 않는다 |
| 첫 문단 없는 항목 | 빈 줄을 두지 않는다 — 첫 하위 블록이 기호 옆에서 시작하고 기호는 그 블록 첫 줄에 맞춘다(`- - a` → `•` `◦ a` 한 줄 · `- # h` → `•` 옆 제목). `-` 만 있는 빈 항목은 기호만 한 줄 |

### 표 — 공통 (NF-5)

| 무엇 | 값 |
|---|---|
| 글자 | 칸 = 본문 크기(크게 · 시스템 배율 따름) · 줄 높이 ×1.5(칸 안 줄바꿈이 잦아 문단 ×1.78 이면 행이 부푼다) · `bodyText` 400. 머리 칸 600 `text`. 칸 안 글자 모양은 위 규칙 그대로 |
| 여백 · 정렬 | 칸 안 가로 12 · 세로 8. 열 정렬을 머리 · 본문 칸 모두 지킨다 · 없음 = 시작 |
| 표 폭 | **내용 폭** — 본문보다 좁으면 늘리지 않고 시작 쪽에 붙는다(넓은 창에서 열 사이가 벌어지지 않게 — DESIGN §5.7) |
| 열 폭 | `## 넘침` 의 세 단계 |
| 가로 스크롤 | 표 전체가 본문 폭 안에서. 가려진 쪽 가장자리 24dp 를 `bg` 로 페이드 — 처음 = 끝 쪽만 · 중간 = 양쪽 · 끝 = 시작 쪽만. 스크롤바 없음 |
| 빈 칸 · 머리만 | 빈 칸은 빈 채로 · 머리만 있는 표는 머리 행 하나 |

### 표 — 후보

| | A 칸 격자 | B 가로선만 |
|---|---|---|
| 테두리 | 바깥 1dp `border` · 반경 10(코드 블록과 같다) · 칸 사이 가로 · 세로 1dp `border` | 바깥 · 세로 없음 · 행 사이 1dp `border` · 마지막 행 아래 없음 |
| 머리 | 바탕 `surface2` | 바탕 없음 · 아래 2dp `border` |
| 가장자리 여백 | 모든 칸 12 | 첫 열 앞 · 마지막 열 뒤 0 — 첫 열 글자가 문단 글자 선에 선다 |
| 스크롤 중 끝 | 상자 테두리가 잘려 보이고, 끝에 닿으면 둥근 모서리가 나온다 | 잘린 글자 + 페이드뿐 |
| 약점 | 선이 많다 · 머리 칸 인라인 코드 바탕이 머리 바탕(`surface2`)에 묻힌다 | 줄바꿈한 칸이 이웃 열과 여백으로만 갈린다 · 끝 표시가 페이드뿐 |
| 판단 | **추천** — 328 에서 줄바꿈 · 가로 스크롤일 때 열 소속이 선으로 남고, 코드 블록과 같은 "본문 안 상자" 라 끌 대상이 분명하다 | 가볍고 본문 글자 선을 지킨다(DESIGN §1 원칙 1에 가깝다) |

### 한도 넘음 (NF-8)

지금 노트 전체 상자(`Unsupported` 노트 전체 — DESIGN §8.6)와 **같은 모양** — 점선 상자 · 제목 `cardTitle` `text` · 본문 `bodySmall` `text2` · `원문 보기`. 제목 · 본문 문구만 다르다(`## 문구`). 한도 숫자는 문구 인자로 받아 한도 상수와 함께 움직인다. `accent` · `warn` · `wrong` 없음.

### 알림 (NF-7)

`> [!NOTE]` 는 인용 그대로 — 첫 줄 `[!NOTE]` 가 인용 글자(기울임 `text2`). 아이콘 · 색 상자 없음(결정 7).

## 넘침

1em = 본문 글자 크기. 열 폭은 여백 뺀 글자 자리 — 여백 24(B 가장자리 열은 12)는 따로 더한다.

| 무엇 | 상한 | 넘치면 |
|---|---|---|
| 열 목표 폭 T | 그 열의 가장 긴 한 줄 폭, 위로 **16em** | 칸 안에서 줄을 바꾼다 |
| 열 최소 폭 M | min(T, max(가장 긴 낱말 폭, **6em**)) | 짧은 열(≤ 6em)은 줄을 안 바꾼다 |
| 표 폭 | ① ΣT ≤ 본문 → 열마다 T(표 = ΣT) ② ΣM ≤ 본문 < ΣT → M 에 남는 폭을 (T − M) 비율로 더함(표 = 본문) ③ ΣM > 본문 → 열마다 M · 가로 스크롤 | 예: compact 3열 짧은 표 = ① · 2열 설명 표 = ② · 5열 표 = ③ |
| 행 수 · 칸 수 | 없음 | 다 그린다(지연 없음 — `## 제약`) |
| 들여쓰기 | 3단 | 4단부터 같은 x · 글머리만 돈다 |
| 기호 칸 | 그 목록에서 가장 넓은 기호 | 자릿수가 바뀌어도 글 시작선이 같다 |
| 항목 안 코드 · 표 | 부모 글 시작선 ~ 본문 끝 | 그 블록 규칙대로(가로 스크롤) |

## 문구

새 화면 문구는 "한도 넘음" 상자 둘(기획 고침 1 · NF-8)뿐 — 나머지는 낭독 낱말. 모두 design-system `ds_`.

| 자리 | 문구 | 뜻 | 안 쓰는 말 |
|---|---|---|---|
| 체크 켬 | 체크됨 | 항목 상태 — 항목 글 뒤에 덧붙여 읽는다(§10.2) | 완료(작성자 뜻을 단정) · 선택됨(누를 수 있다는 뜻) |
| 체크 끔 | 체크 안 됨 | 같음 | 미완료 · 할 일 |
| 취소선 앞 | 취소선 | 줄 그은 구간이 시작됨 | 삭제됨 · 지움(뜻을 단정) |
| 취소선 뒤 | 취소선 끝 | 그 구간이 끝남 | |
| 한도 넘음 상자 제목 | 이 노트는 읽기 한도를 넘었습니다 | 앱이 일부러 읽지 않은 노트 — 형식 오류 상자와 구별 | 깨졌습니다 · 오류(파일 탓으로 단정) |
| 한도 넘음 상자 본문 | 목록이나 인용이 %1$d단보다 깊게 겹쳤거나 파일이 %2$dKB를 넘어 읽지 않았습니다. 파일을 나누거나 겹침을 줄이면 다시 읽습니다. | 원인 둘 + 다음 수(DESIGN §1 원칙 6) · 인자 32 · 512 | 앱을 업데이트하면(업데이트로 풀리지 않는다) |
| 표 | 없음 | 시스템이 행 · 열 수를 읽는다(`collectionInfo`) · 머리 칸은 제목(`heading`) | 앱이 "표" 를 또 붙이기(두 번 읽힘) |

체크 항목은 기호 · 글을 한 덩어리로 읽는다 — 체크 상자 아이콘 설명은 비운다. 체크 상자에 체크박스 역할을 주지 않는다(누를 수 있다고 읽힌다).
