## 폭

| 이름 | 값 | 바뀌는 것 |
|---|---|---|
| compact | 폰 세로 360×800dp · 다크 | 기본 — 카드 세부 · 알약 라벨 · 알림 본문 자리가 가장 좁다 |

넓은 창(Medium · Expanded)은 설정 열이 가운데 최대 폭이라 세부 자리가 더 넓다 — 시안은 compact 만(가장 좁은 곳). 글자 배율은 알약만 1.3 을 따로 그렸다(`## 넘침`).

## 상태

상태 × 폭 = 시안 장수 예산(검토 예산 5장). 빈 칸 = 안 그림.

| 상태 | compact 1.0 | compact 1.3 |
|---|---|---|
| 카드 · 재시도 + 알림 꺼짐 | ✓ | |
| 카드 · 멈춤 + 알림 꺼짐 | ✓ | |
| 알약 · 재시도 | ✓ | ✓ |
| 알림 · 막대 세 종류 | ✓ | |

안 그린 것: 카드 · 알약의 Wi-Fi 대기 · 준비 · 받는 중 · 파일 확인 · 사용 가능 · 실패 · 없음 — 이번에 그림이 안 바뀐다(ST §10.2 · §10.4 그대로). 카드 1.3배는 세부가 ≈ 9자 상한 안이라 계산으로 갈음. 알림은 상태마다 그리지 않는다 — `## 알림` 표가 원본이고 그림은 모양 한 장(판마다 다른 시스템 모양을 흉내 내면 오해를 부른다).

| 무엇 | 상한 | 넘치면 |
|---|---|---|
| 카드 세부 | 한 줄 ≈ 12자(1.0) · ≈ 9자(1.3) | 말줄임. `이어서 받습니다`(한글 7 + 띄움 1)는 두 배율 다 들어간다(계산) |

| 알림 제목 | 한 줄 | 잘림. `퀴즈 모델을 받고 있습니다` 는 들어간다 |

| 실패 알림 본문 | 펼치면 여러 줄 | 접히면 잘림(BigTextStyle — 기존) |
| (기존 · 범위 밖) 멈춤 카드 버튼 줄 | 360dp 에서 242dp | `이어 받기` + `받던 파일 지우기` ≈ 254dp(계산) — 지금 `Row` 라 둘째 버튼이 눌린다(못 봄). 시안 2번은 줄을 바꿔 그렸다 — 그림이지 규칙이 아니다. 멈춤 카드 `@Preview` 에서 확인 거리 |

## 색

다크 단일 팔레트 · 새 색 없음 · 점과 링 옆에는 늘 글. 재시도 = `warn`(점 · 링 · 막대 — §2.3 "기다림 · 재시도") · 멈춤 = `text3`(점 · 막대) · 알림 꺼짐 안내 = `warn` 8% 면 / 20% 테두리 + `warnText` 글 + `켜기` `warn`(지금 값). 시스템 알림은 **색을 정하지 않는다** — 막대 · 틀은 안드로이드 기본(`## 제약`). 재시도와 받는 중 알림은 글 · 막대 멈춤 · 작은 아이콘으로 갈린다(색이 아니라).

| 테마 | 확인 |
|---|---|
| dark (유일) | `r1/` 5장 · 대비 숫자는 바뀐 색이 없어 기존 값(DESIGN.md §10.2) |

## 문구

용어표 원본. 키는 `strings.xml` 이 정한다(feature `notes_` · core/ai `ai_`). 합니다체 · 상태 라벨은 마침표 없음 · 안내 문장은 마침표.

**용어 — `받` 하나.** 화면 · 알림에 보이는 진행 · 상태 · 결과는 `받` 계열이다(받기 · 받는 중 · 받았습니다 · 받지 못했습니다 · 이어서 받습니다). `내려받기` 는 작업 이름(명사)으로만 남는다 — 알림 채널 이름 `모델 내려받기`(채널은 안 바꿈) · 지금 스낵바 `내려받기를 …`(범위 밖 · 열린 질문 1). **한 알림 안에 두 말을 섞지 않는다** — 그래서 진행 알림 제목이 바뀐다.
**재시도 글이 하지 않는 말:** 원인 단정(`연결` — 서버 오류도 재시도다) · 시점(`곧` · `잠시 뒤` · `N초`) · 계기(`연결되면`) · 버튼 말(`다시 시도` 로 끝나기).

| 자리 | 문구 | 키 | 대안 | 안 쓰는 말 |
|---|---|---|---|---|
| 카드 재시도 라벨 | 받기 끊김 | `notes_model_retrying` (값 바뀜) | `연결 끊김`(지금 — 원인 단정) · `중간에 끊김` | 다시 시도 · 오류 |
| 카드 재시도 세부 | 이어서 받습니다 | `notes_model_retrying_desc` (인자 없음 · `%` 0) | `자동으로 이어 받습니다`(1.3배에서 잘림) · `받은 자리부터 이어 받습니다`(1.0배에서 잘림) | N초 뒤 다시 시도 · 연결되면 · 곧 |
| 알약 재시도 라벨 | 받기가 끊겨 기다리는 중 | `notes_pill_retrying` (값 바뀜) | `연결이 끊겨 기다리는 중`(원인 단정) · `받기 끊김`(카드와 같은 말 · 짧다) | 연결이 끊겨 다시 시도(버튼 말) |

| 진행 알림 제목 | 퀴즈 모델을 받고 있습니다 | `ai_model_download_title` (값 바뀜) | 지금 `퀴즈 모델을 내려받고 있습니다`(본문과 갈림) | 내려받고 |

| 재시도 | 〃 | 받기가 끊겼습니다. 이어서 받습니다 | 값 · **멈춤**(받은 비율 · 갱신 없음) | 취소 | **새 정적 벡터**(아래) | 아니오 | 뒤 절이 잘릴 수 있음 — 앞 절이 핵심 |
| 파일 확인 | 〃 | 파일을 확인하고 있습니다 | 움직임 | 없음 | 플랫폼 `stat_sys_download` | 아니오 | 들어감 |
| 사용 가능(방금) | 퀴즈 모델을 받았습니다 | 이제 노트에서 퀴즈를 만들 수 있습니다 | 없음 | 없음 | 플랫폼 `stat_sys_download_done` | 예 — 누르면 사라짐 | 본문 끝이 잘릴 수 있음 |
| 받지 못함 | 퀴즈 모델을 받지 못했습니다 | 잠시 뒤 다시 시도해 주세요 / 저장 공간 문구(지금) | 없음 | 다시 시도 | 플랫폼 `stat_notify_error` | 예 — 누르면 사라짐 | 펼침(BigTextStyle) |

- 막대 종류 = `setProgress` 세 갈래: 없음(안 부름) · 움직임(indeterminate) · 값(최대 100 · 값 n). 재시도의 값은 받은 비율에서 한 번 그리고 바꾸지 않는다.
- **재시도 작은 아이콘(결정 12 — 그림은 여기서 정함):** core/ai 새 벡터 drawable `ai_stat_download_retrying`(이름은 개발 몫 · `ai_` 접두사). 그림 = Material Symbols `downloading` 실루엣(끊긴 원 + 아래 화살표 · Apache-2.0) · 24dp · 흰 단색 · **정적**. 알약의 멈춘 링과 같은 말(원 + 끊김)을 하고, 받는 중의 움직이는 화살표와는 움직임으로 갈린다.
  대안: 플랫폼 `stat_notify_sync_noanim`(새 파일 0 · 동기화 화살표라 계정 동기화로 읽힐 수 있다). 버림: `stat_sys_download_done`(끝남으로 읽힌다) · `stat_sys_warning`(경고 — 실패 아이콘과 다툰다).
- 지울 수 있나 `아니오` = 앱이 ongoing 을 건다는 뜻이다. 안드로이드 판에 따라 사용자가 밀어 지울 수 있다 — 시스템 몫 · 못 봄(기능 문서 열린 질문 5).
- 모양 그림: `r1/알림-막대 세 종류-compact.png` — 판 · 제조사 흉내 없는 일반 틀.

**순서 — 한 번에 하나, 남는 알림 없음(MD-10 · MD-11).** 받아들임 기준은 기능 문서다 — 이 표는 사용자가 알림창에서 보는 것.

| 사건 | 그 전에 떠 있던 것 | 그 뒤 떠 있는 것 |
|---|---|---|
| 받기 시작 · 다시 시도 | 받지 못했습니다 | 실패 알림은 사라짐 · 준비 하나(Wi-Fi 가 없으면 없음 — 앱이 뒤로 갈 때 대기 알림) |
| 받다가 끊김(연결 · 서버 오류 · Wi-Fi 끊겨 멈춤) | 받는 중 | 재시도 하나 — 막대가 그 자리에서 멈추고 아이콘이 멈춘 그림으로 |
| 다시 받기 시작 | 재시도 | 받는 중 하나 — 아이콘이 다시 움직임 |
| 앱이 뒤로 감 | 대기 · 재시도인데 알림 없음(앱 안 알약만) | Wi-Fi 대기면 대기 알림 · 재시도면 재시도 알림 · 그 밖은 건드리지 않음 |
| 앱이 앞으로 옴 | 대기 · 재시도 알림 | 그대로 남음(결정 11) — 알약과 겹쳐도 괜찮다 |
| 다 받음 | 받는 중 → 파일 확인 | 받았습니다 하나 |
| 실패 | 진행 계열 무엇이든 | 받지 못했습니다 하나 |
| 취소(앱 · 알림 액션 · 돌던 중 · 쉬던 중) | 진행 계열 무엇이든 | **없음** |
| 모델 삭제 | 받았습니다 | **없음** |

자리가 바뀌면(진행 ↔ 재시도 ↔ 결과) 알림창에서 한 번 빠졌다 들어올 수 있다 — 채널 중요도가 낮아 소리 · 팝업은 없다(못 봄 · 메인 기기 확인 거리).
