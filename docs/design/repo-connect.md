## 색

다크 단일 팔레트 · 새 색 없음 · 점 옆에는 늘 라벨. 공개 · 토큰 사용 · 성공 점 `correct` · 토큰 확인 필요 점 · 배지 · 실패 안내 `warn`+`warnText`(사용자 탓 아님) · 연결 없음 · 결과 없음 점 `text3` · 마지막 결과 실패 줄 `text2` · 최종 삭제는 확인 대화상자 안만 면 `wrong` + 글자 `bg`. **입구 구역(새 색 없음)**: 제목 `text` · 한 줄 `text2` · 단계 글 `bodyText` · 번호 배지 `surface2` 원 + 번호 `text2` · 비공개 줄 `text3` · 구분 선 `border` + `또는` `text3` · 입구 버튼 `surface2` + `border`(accent 면 없음). RC-9 상자는 기존 warn 8%/20%, 두 번째 길은 `text2` 조용한 버튼. 테마 확인: dark(유일) — 시안 · 실화면 사진.

## 문구

용어표 원본. 키는 `strings.xml`(`notes_` · 공통 `ds_*`)이 정한다 — 차수 2 새 글만 키 후보를 적는다. 합니다체 · 상태 라벨은 마침표 없음 · 안내 문장은 있음.

**`템플릿` 은 쓴다**(입구 한 줄 · 단계 ① · RC-9 한 줄 — 일반어, 템플릿 README 도 같은 말, NT-5 ⑤). **안 쓰는 말**: 레포 · Fork · Use this template · 새로 만들기 · 템플릿 보기. 기능 문서의 `새로 만들기` · `템플릿 보기` 는 작업 이름이고 화면 이름은 이 표가 정한다(검수 때 RC-9 · RC-25 를 맞춘다).
