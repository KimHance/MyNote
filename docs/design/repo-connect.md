## 문구

용어표 원본. 키 후보는 뜻 칸(`notes_` · 공통 `ds_*`). 합니다체 · 상태 라벨은 마침표 없음 · 안내 문장은 있음.

**읽는 중**(시작 판정 · 화면 아직 없음) · **가져오는 중**(연결 화면 첫 동기화 · 닫을 수 없음) · **받는 중**(홈 빈 상태 · 이미 연결됨)은 서로 다른 상태다.
