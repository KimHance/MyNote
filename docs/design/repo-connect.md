다크 단일 팔레트(라이트 · 색약 · ansi 없음, DESIGN §2.1) · 새 색 없음 · 점 옆에는 늘 라벨.

| 뜻 | 토큰 |
|---|---|
| 공개 · 토큰 사용 · 성공 점 | `correct` (공개의 토큰 없음은 정상, 결정 18) |
| 토큰 확인 필요 점 · 드로어 배지 · 실패 안내 아이콘 | `warn` · 글자 `warnText` (사용자 탓 아님 → `wrong` 아님) |

## 문구

용어표 원본. 키 후보는 뜻 칸(`notes_` · 공통 `ds_*`). 합니다체 · 상태 라벨은 마침표 없음 · 안내 문장은 있음.

**읽는 중**(시작 판정 · 화면 아직 없음) · **가져오는 중**(연결 화면 첫 동기화 · 닫을 수 없음) · **받는 중**(홈 빈 상태 · 이미 연결됨)은 서로 다른 상태다. `## 상태` 의 **첫 동기화 중** = 화면 문구 **가져오는 중**(같은 상태).
