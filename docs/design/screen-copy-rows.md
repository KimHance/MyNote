# 화면 문구 — 바꾼 문구 표

| 항목 | 값 |
|---|---|
| 기능 | screen-copy |
| 디자인 문서 | docs/design/screen-copy.md (용어 표 · 끝말 · 쓰지 않는 표현 · 한 줄 고정 자리 · 같이 바뀔 것) |
| 기준 | 값은 9effa35 의 `strings.xml` 넷 — 문구 395개 중 56행 |
| 마지막 변경 | 2026-10-11 · `ui_sync_changed` 행 인용 칸을 sync 결정 5 로(copy-spec 이 찾은 인용) |

copy-apply 가 이 표대로 `strings.xml` 값만 바꾼다. 리소스 이름 · 형식 자리(수 · 순서 · 종류) · 배열 항목 수는 그대로다(SC-5).
표에 없는 문구는 값이 기준과 같아야 한다(SC-4). 끝난 뒤 사용자에게는 이 표의 바뀐 행만 보인다(기능 문서 결정 4).

| 칸 | 뜻 |
|---|---|
| 리소스 이름 | 시험이 읽는다 — 기준 커밋과 값이 다른 이름의 집합이 이 칸의 집합과 같아야 한다 |
| 자리 | DESIGN 9.4 문장 모양 표의 자리. `한 줄` 이 붙은 행은 디자인 문서 한 줄 고정 자리 |
| 지금 · 바꿀 것 | XML 값 그대로(두 글자 `\n` 포함). 따옴표 · 꺾쇠 이스케이프는 copy-apply 가 붙인다 |
| 길이 | 바꿀 것 − 지금, 글자 수. 버튼 · 상태 라벨 · 탭 라벨 · 한 줄 행은 0 이하(SC-6) |
| 인용한 기능 문서 | 이 값을 글자 그대로 인용한 기능 문서 항목 — copy-spec 이 같이 고친다 |
