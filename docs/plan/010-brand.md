# Brand identity and document hygiene

Source: rebuilt from the old feature document `docs/spec/brand.md` as of commit c8c54350 (work of 2026-10-08, with the start-screen changes of 2026-10-14 that the document records).

## Plan
- why: The launcher icon, theme icon and system splash were the Android default robot, the home hero was an accent square with an `N`, and the home bar and reader titles used a temporary name that differed from MyNote. Brand direction A (a lit lamp: two arched windows forming an m, accent frame, night background, light only in the right window) is applied everywhere the app shows itself. Tracked documents also carried local paths and conversation context with no check to keep them out.
- flow: The person finds the A mark on the home screen or drawer (a tinted silhouette with themed icons); tapping it shows a night splash with the mark whose right window lights once, then the first screen, a short loading screen if the start decision is pending, and home with the mark, the lower-case `mynote` wordmark and the connected owner/repo. Title-style text is Gothic A1 when the font arrives in time, else the device font for that process.
- not doing: No repository title field in the notes list (it would break old apps' sync); no body font change and no font file in the APK; no light-theme icon or splash; no branch or visibility in the hero; no README banner, store graphics or share card; no change to the download notification's small icon; the splash does not wait for data; the project's own coordinates are not on the hygiene deny list; git history and old commit bodies are not rewritten.
