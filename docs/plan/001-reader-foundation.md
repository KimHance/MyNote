# Reader foundation

Source: rebuilt from the git log 2026-06-24 … 2026-09-12 (first commit d92a6c0e to 30269ec3), the owner's earlier planning notes under `docs/prd/` (untracked) and the module `AGENTS.md` files, checked against the code at commit 06e0ad15.

## Plan
- why: A person who keeps study notes in a GitHub repository wants to read them in a phone-and-tablet app that works from a local cache, finds a note quickly, and feels as steady on a foldable as on a phone.
- flow: The app syncs the repository's notes into the cache, home shows the newest notes, the list panel (drawer or fixed pane) finds a note by category or search, the reader shows it, and settings hold the text size and the access token.
- not doing: No writing or editing of repository notes. No Markdown (009), bookmarks (004), statistics (005), repository connecting (007), quiz (002), model download (003) or brand (010). Dark theme only; no light theme, no other language.
