# Quiz

Source: rebuilt from the git log 2026-09-15 … 2026-09-26 (commits 9ced6219 to 18551095 and their fixes), the owner's earlier planning notes `docs/prd/features/quiz-generation.md` and `docs/prd/screens/quiz.md` (untracked), `core/ai/AGENTS.md` and `feature/quiz/AGENTS.md`, checked against the code at commit 06e0ad15.

## Plan
- why: After reading a note the reader wants to test what stuck, and the note must not leave the device, so a language model on the phone turns the note into multiple-choice questions.
- flow: At the end of a note the reader taps the quiz card, picks up to 3, 4 or 5 questions, waits while the model writes them, answers one by one with instant grading and an explanation, sees a score and goes back to the note; failures offer a retry.
- not doing: No saved quiz history or review screen (attempts feed statistics, 005); no cloud model; no generation-time undo; no custom question types or free-text answers. Downloading the model is 003 and quiz results recorded for statistics are 005.
