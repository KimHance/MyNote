# Repository connect

Source: old feature document `docs/spec/repo-connect.md` as of commit c8c54350 (work of 2026-10-05 and 2026-10-06, template entry added 2026-10-06, wording and entry hierarchy updated by the local-notes work of 2026-10-14) and the owner's earlier planning notes (untracked).

## Plan
- why: The repository the app read was fixed at build time and a private repository could only be reached through a token field in settings, so a person who installed the app could not connect their own notes, and the token showed as connected even when wrong.
- flow: The user pastes a repository or list link on the connect screen, the app tries without a token, asks for a token only when the repository is not visible or the limit is hit, runs a first sync and confirms the connection; later the user changes, disconnects or re-tokens from the settings card.
- not doing: No OAuth login or repository picker, no several repositories at once, no Markdown-only repositories, Gist or single-file links, no token encryption or expiry display, no clipboard reading or paste button or return deep link, no app-created repositories (the entry only opens GitHub), no up-front token request.
