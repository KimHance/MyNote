# Device notes

Source: old feature document `docs/spec/local-notes.md` (v3) as of commit c8c54350; work done 2026-10-14 (stage 1, merged as f141309c).

## Plan
- why: The app needed a repository created and connected before any note showed, so a first-time user had to know GitHub, templates and tokens; the repository becomes optional and a user starts by writing a note or importing one (shared text, a `.md` file, pasted text), while connected repository notes, bookmarks, quiz and stats records stay alive.
- flow: First run (no connection, no notes) shows the home first-run empty state with New note, Import and a quieter Connect repository entry; New note opens an editor (title, group, Markdown body, preview as the reader draws it) and Save opens the note in the reader; Import by file, paste or share opens a prefilled new-note editor and a note exists only after Save; a device note can be edited and deleted from the reader, a repository note cannot; device notes join search, bookmarks, quiz and stats; connecting, changing or disconnecting a repository leaves device notes alone.
- not doing: No editing or deleting of repository notes in the app, no upload of device notes to a repository, sync or turning a repository note into a device note (stage 3), no new repository attach shape such as several repositories or folder scans (stage 2), no URL scraping, no format buttons, autocomplete or toolbar, no export of device notes, no multi-file import, images or attachments, no automatic clipboard reading, no autosave of unsaved text.
