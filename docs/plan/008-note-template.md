# Note template and public kit

Source: rebuilt from the old feature document `docs/spec/note-template.md` as of commit c8c54350 (work of 2026-10-06, Markdown move 2026-10-12, template made self-contained 2026-10-13 and 2026-10-14).

## Plan
- why: A person without a notes repository had nowhere to go: the note format, the index file and the checks lived only in the project's internal documents and a local commit hook. A template repository with a ready index and a check that GitHub runs on every push lets a newcomer connect and see example notes at once, with no local tools.
- flow: In the app the person opens the repository-creation entry, makes a repository from the template on GitHub and pastes its address into the app; the example notes show. Each later push of notes under `notes/` makes the template's workflow run its own copy of the tool, which checks every note and rebuilds `notes/index.json`; a failed check leaves the old index.
- not doing: No actual GitHub publishing, repository creation, template flag or marketplace registration (the owner does these by hand, and only after an app that reads Markdown has shipped). No change to the project's own `notes/`, `notes/SCHEMA.md`, `notes/gen_index.py`, hook or `write-note`. No body checking by the tool. No folder-scan repositories without an index, no app-side repository creation by login, no format-explainer screen in the app.
