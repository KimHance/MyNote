## 6. 후보 21A · 21B 비교

21A 는 히어로 힌트 아래에 라벨이 있는 보조 버튼 두 개를 두어 입구를 글자로 보이고, 버튼 행 높이(56dp)만큼 `최근 노트` 가 아래로 밀립니다. 상단 바는 바뀌지 않습니다. 21B 는 히어로 · 목록 위치가 지금과 같고, 상단 바 오른쪽에 아이콘 두 개를 새로고침 앞에 더해 오른쪽 터치 자리가 48 에서 144 로 늘어납니다. 21B 의 두 입구는 라벨이 없어 접근성 이름(`가져오기` · `새 노트`)과 길게 누름 툴팁에 기댑니다. 21A 는 스크롤하면 버튼이 화면 밖으로 나가고, 21B 는 상단 바에 있어 스크롤과 무관하게 남습니다.

## 7. 넘침 규칙

- 편집기 제목 칸 · 그룹 칸: 한 줄 고정. 넘치면 줄바꿈 없이 가로로 흐름(`singleLine = true`, 커서를 따라 가로 스크롤).
- 상단 바 제목: 한 줄 말줄임.
- 카드 칩: 한 줄 · 최대 폭 120 · 끝 말줄임. 날짜 · 이 기기 표기는 줄이지 않음. 카드 제목은 줄바꿈.
- 목록 패널 그룹 이름 · 노트 행: 한 줄 말줄임. 글리프는 줄이지 않음.
- 버튼 라벨: 모두 한 줄 고정(큰 글자 포함). 빈 상태 묶음 폭 240 · 가로 180 은 ×1.3 에서도 라벨이 들어감.
- 이유 줄: 줄바꿈 허용.
- 빈 상태 묶음: 화면보다 길면 묶음 전체를 세로 스크롤(가운데 정렬은 남는 높이가 있을 때만).

## 8. 수용 기준

- [ ] 새 색 토큰이 없다(§1 값만)
- [ ] 한 묶음에 주 버튼은 하나다(빈 상태 `새 노트` · 편집기 `저장`)
- [ ] 편집기는 ☰ · 플로팅 내비 · 모델 알약을 숨긴다
- [ ] 저장 꺼짐에서 투명도 0.4 + 이유 줄이 보인다
- [ ] 크기 넘음 이유 줄은 warn 아이콘 + warnText 다
- [ ] `버리기` 는 대화상자 안에서만 wrong 면이다
- [ ] 가로 빈 상태는 타일을 숨기고 스크롤 없이 한 화면이다
- [ ] 기기 노트는 카드 · 목록 행 · 미리보기에서 이 기기 글리프로 표기된다
- [ ] 버튼 라벨은 큰 글자에서도 한 줄이다
