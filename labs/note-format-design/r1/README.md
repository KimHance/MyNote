- 규칙의 정본은 `docs/design/note-format.md` `## 모양` · `## 넘침` 이다. 이 폴더는 그 규칙을 그린 그림이다.
- 원본: Claude Design 프로젝트 `190a5d4b` 의 `Note Format.dc.html` · 핸드오프 `design_handoff_note_format/` · 요청서 `briefs/note-format-r1.md` (대화 `d3aab3ef`).
- 1x PNG · 디자인 px = dp · 다크(유일). 노트 · 날짜는 가짜다.
- **HTML 은 안드로이드의 한글 합성 기울임 · 줄긋기 위치 · `◦` `▪` 글리프와 다르게 보일 수 있다 — 규칙이 정본이고 실화면은 PreviewActivity 견본 사진으로 본다.**

## 표 예시와 열 폭 (여백 포함 · 그린 값)

① `컬렉션 | 순서 | 평균 조회` 정렬 `:--` `:-:` `--:` · ② `범위 | 값이 사라지는 때`(설명 열) · ③ `기능 | LiveData | StateFlow | SharedFlow | Channel`.

B 는 첫 열 앞 · 마지막 열 뒤 여백이 0 이라 같은 내용에서 24 좁다. 본문 폭에 맞던 표(② 328)는 그 24 를 줄바꿈 열이 가져간다.

- 큰 글자 줄은 1em 23.4(18 × 1.3 선형)로 그린 값이다. 실제 1em 은 `body.fontSize` 를 dp 로 한 번 바꾼 비선형 값이라 기기에서 조금 다르다(문서 `## 정한 것` 6).
- 표 ② 첫 열 197 은 코드 구간 `rememberSaveable` 을 앞뒤 여백까지 한 낱말(18칸 × 0.6em = 173 + 여백 24)로 잰 값이다(문서 `## 넘침` M). HTML 은 코드 칩을 본문보다 작게 그려 열이 남아 보인다 — 앱 코드 구간은 본문 크기 고정폭이다.
