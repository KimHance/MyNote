## 2. 화면 구성 규칙

| 화면 | 상단 바 | 플로팅 내비 · 드로어 · 모델 알약 · 새로고침 · 맨 위로 |
|---|---|---|
| 첫 실행 연결 화면(루트) | **없음**. 큰 제목 `노트 저장소 연결` + 안내 + 칸 + `연결` | 모두 없음 |
| 쌓은 연결 화면(설정 › 저장소 바꾸기 / 홈 › 연결하기) | 뒤로 + 제목. 제목 두 가지: 연결이 있을 때(설정에서 연 화면) `저장소 바꾸기` · 연결이 없을 때(홈 연결 안내에서 연 화면) `저장소 연결`. 첫 동기화 중에는 뒤로 아이콘 alpha 0.4 · 눌러도 아무 일 없음 | 모두 없음 |

연결 화면의 자리는 이 **둘**뿐입니다. 홈에서 연 화면도 별도 배치가 아니라 쌓은 화면과 같은 구성이고 제목만 다릅니다.
| 설정 | 뒤로 + `설정` + 새로고침(기존) | 내비 없음(기존 규칙) |
| 홈 | ☰ + 제목 + 새로고침 | 내비 있음(Compact 하단 바 · Medium+ 우측 레일) |

- 연결 화면 본문은 **가운데 한 칼럼 최대 560dp**, 좌우 16dp. 852 에서는 양옆이 빕니다(목록 칸·레일 없음).
- 위 여백: compact 루트 52dp · 852 루트 96dp · 쌓은 12dp. 요소 간격 24dp(가로 16dp).
- 토큰 입력은 **대화상자가 아니라 같은 화면에서 토큰 카드를 펼칩니다.** 순서: 제목·본문 → 만드는 법 3줄 → `토큰 만들기` → `액세스 토큰` 칸 → (안내 상자). 카드 밖 아래에 `연결`. 만드는 법을 칸 위에 두어 키보드가 올라와도 토큰 칸과 `연결` 이 같이 보입니다.
- 키보드(가로 800×360): 본문을 `imePadding` + `bringIntoView` 로 포커스 칸까지 올립니다. 결과적으로 칸 + `연결` 이 키보드 바로 위에 함께 남고 제목은 위로 잘립니다.
- 상태 점 옆에는 항상 라벨. 실패 안내는 빨강이 아니라 warn 계열(사용자 탓이 아님).
- 안전 여백: 상태바 24dp, 제스처 내비 24dp. `WindowInsets.safeDrawing` 을 그대로 씁니다.
- 대화상자: 유리(glassPanel 66%, blur 20, 1dp 흰 9% 테두리), 반경 26, **최대 폭 420dp**, 좌우 바깥 여백 24dp, 위아래는 시스템 바 + 24dp 를 뺀 높이가 최대 높이. 제목·본문은 내부 스크롤 영역(`verticalScroll`), 버튼 줄은 스크롤 밖에 고정되어 항상 보입니다. 버튼 오른쪽 정렬 `취소`(보조) + 확인. 바텀시트 금지.
- 큰 글자(글자 배율 ×1.3): 글자만 커지고 dp 는 그대로. 버튼 줄은 `FlowRow` — 한 줄에 안 들어가면 줄을 바꾸고 라벨은 항상 한 줄(잘림·말줄임 없음).

### 3.4 카드 · 편집기 — 13장 (설정 › `노트 저장소` 카드)

카드 문법은 기존 토큰 카드와 같습니다: 40dp 아이콘 타일 · 제목 `노트 저장소` cardTitle · 상태 줄(점 7dp + 라벨 13/500 bodyText + 마스크 mono 12.5 text2) · 아래 설명 13 text3. 본문 들여쓰기 70dp.
본문 순서: **저장소 줄 → 마지막 결과 줄 → 구분선 → 저장소 버튼 줄 → 구분선 → `액세스 토큰` 블록.**
- 저장소 줄: 라벨 `저장소`(caption 13 text2) + 값 `octo-learner/android-notes · 브랜치 main · 노트 위치 notes`(값 mono 12.5 bodyText).
- 마지막 결과 줄: 점 + 라벨.
- 저장소 버튼 줄: `저장소 바꾸기`(보조) · `연결 끊기`(파괴적). 242dp(본문 들여쓰기 70dp 제외)에 한 줄로 들어가고, 안 들어가면(큰 글자) 줄을 바꿉니다. 라벨은 한 줄.
- `액세스 토큰` 블록: 라벨 + 마스크(mono 12.5) 또는 `토큰 없음 · …` + 버튼 `바꾸기` · `지우기`. 이 `바꾸기` 의 **접근성 이름은 `토큰 바꾸기`**(`contentDescription`/`semantics`; 화면 글자는 `바꾸기`).
- 화면에서 `바꾸기` 는 토큰 블록에만 있고 저장소 쪽은 `저장소 바꾸기` 입니다. 옛 섹션 라벨 `GitHub` 은 지웁니다.

## 5. 문구

화면의 모든 문구는 브리프의 용어표 그대로입니다(합니다체, 상태 라벨에는 마침표 없음). 표에 없는 새 문장은 없습니다. 예외로 기존 문자열을 그대로 재사용한 곳: `설정`, `읽기`, `본문 글자 크게`, `노트 본문을 16에서 18로 키웁니다`, `토큰 입력`, `보기`, `이 기기에만 저장됩니다.`, `노트`, `노트 검색`, 통계의 `이번 주 · 이번 달 · 전체`, `읽기 · 퀴즈 · 북마크`, `읽다 멈춘 노트`, `%1$d%%에서 멈춤`.
대화상자의 숫자 예시: 노트 24개 · 북마크 3개(바꾸기 · 끊기), 노트 5개(이어받기).
이번에 추가된 문구: `저장소`(카드 저장소 줄 라벨) · `저장소 바꾸기`(카드 버튼) · `저장소 연결`(홈에서 연 쌓은 화면 제목) · `저장된 토큰이 지워집니다.`(바꾸기 대화상자 토큰 줄) · `노트를 고르세요`(852 빈 상세) · 접근성 이름 `토큰 바꾸기`.

## 6. 수용 기준

- [ ] 첫 실행 루트에 상단 바·플로팅 내비·드로어·모델 알약·새로고침·맨 위로가 없다
- [ ] 연결 화면 자리는 루트 · 쌓은 화면 둘뿐. 쌓은 화면 제목은 `저장소 바꾸기`(연결 있음) / `저장소 연결`(연결 없음), 내비·드로어·알약 없음
- [ ] 첫 동기화 중 쌓은 화면의 뒤로 아이콘은 alpha 0.4 이고 아무 일도 하지 않는다
- [ ] 설정 카드에서 `바꾸기` 는 토큰 블록에만 있고(접근성 이름 `토큰 바꾸기`), 저장소 쪽은 `저장소 바꾸기`
- [ ] 편집기 확인 중에는 `취소` 활성 · `저장소 바꾸기` · `연결 끊기` 비활성
- [ ] 글자 ×1.3 에서 버튼 줄이 줄바꿈되고 라벨이 잘리지 않는다. 대화상자 버튼 줄은 항상 보인다
- [ ] 연결 본문은 최대 560dp 가운데 한 칼럼, 852 에서 양옆이 빈다
- [ ] 가로 + 키보드에서 포커스 칸과 `연결` 이 키보드 위에 함께 보인다
- [ ] 빈 칸 이유는 힌트 톤, 나머지 링크 이유·실패·토큰 실패는 warn 계열
- [ ] 토큰 입력은 대화상자가 아니라 같은 화면의 토큰 카드 / 설정 카드 안 편집기
- [ ] 확인 중에는 칸 잠금 + 버튼 비활성, 뒤로 = 요청 취소
- [ ] 첫 동기화 중에는 닫을 수 없다
- [ ] 상태 점마다 라벨이 붙는다
- [ ] 대화상자 최대 폭 420dp, 반경 26, 최종 삭제(바꾸기 · 끊기)만 wrong 면
- [ ] 홈 연결 안내 띠에 닫기 버튼이 없고 띠 전체가 연결 화면을 연다
- [ ] 닫는 것·누르는 것 모두 터치 48dp 이상
- [ ] 화면·로그·스크린샷 테스트에 실제 저장소 주소나 토큰 원문이 나오지 않는다
