# 노트 형식

이 문서는 `notes/` 노트 파일의 **계약**이다. 쓰기 스킬(`write-note`)과 손편집 모두 이 문서를 따른다.
노트는 앞머리 + 마크다운 본문인 `.md` 파일이다. 옛 JSON 노트는 읽기 호환으로만 남는다(8절).

> 앱은 본문을 GFM 마크다운으로 해석해 블록으로 그린다. 그리지 못하는 문법은 글자로 보인다.
> 원문 상자는 해석이 실패했거나 한도를 넘은 노트에만 뜬다.
> `gen_index.py` 는 앞머리만 검사하고 본문은 보지 않는다 — 앱이 어떤 본문도 읽기 때문이다.
> 마크다운 노트가 그것을 읽는 앱 판보다 먼저 원격에 올라가면 옛 앱에서 노트마다 상자로 보인다. 앱 업데이트가 먼저다.

---

## 1. 디렉터리 / 파일 배치

```
notes/
├── index.json          # gen_index.py 가 생성(직접 편집 금지)
├── SCHEMA.md           # 이 문서
├── gen_index.py        # 생성기
└── <group>/<id>.md     # 노트 1개 = 파일 1개. 폴더명 = 카테고리(group)
```

- `group` = 폴더 이름, `id` = 파일 이름에서 `.md` 를 뺀 것. 노트 안에 다시 쓰지 않는다.
- `id` 는 전역 유일하다. 옛 `.json` 노트의 `id` 와 겹쳐도 생성기가 실패한다.
- 확장자는 소문자 `.md`. `.MD` 같은 대소문자 변형은 생성기가 실패로 말한다.

## 2. 앞머리

```markdown
---
title: Compose 상태 관리 정리
date: 2026.06.12
---
## 왜 상태를 끌어올리나

상태를 가진 쪽이 **하나**여야 화면이 어긋나지 않는다.
```

- 첫 줄이 정확히 `---`, 그 뒤 `키: 값` 줄들, 다음 줄이 정확히 `---`. 앞뒤 공백이 붙은 `---` 는 경계가 아니다.
- 키는 `title`(필수) · `date`(필수, `YYYY.MM.DD`) 둘뿐이다. 같은 키를 두 번 쓰지 않는다.
- 값 = 첫 `:` 뒤에서 앞뒤 공백과 감싼 따옴표 한 쌍을 뺀 것. `title: "Flow: 기초"` → `Flow: 기초`. 이스케이프는 풀지 않는다.
- 앞머리 안에 빈 줄 · `#` 줄 · 콜론 없는 줄을 두지 않는다.
- 읽기 전에 맨 앞 BOM 을 떼고 줄 끝(CRLF · CR)을 LF 로 바꾼다. 해시는 파일 바이트 그대로다.
- 앞머리는 블록이 되지 않는다. 제목 · 날짜는 앱이 `index.json` 값을 쓴다. 본문의 `#` 제목은 본문 블록이다.
- 앱은 경계만 본다 — 경계가 없거나 닫히지 않으면 파일 전체가 본문이다. 생성기는 그런 노트를 실패로 말한다.

## 3. 본문 — 문법과 블록

| 문법 | 앱에서 |
|---|---|
| `#` ~ `######` | 제목, 단계 1 ~ 6 (보이는 모양은 2 이하 · 3 이상 둘) |
| 밑줄 제목 `===` · `---` | 제목 1 · 2 — 쓰지 않는다(5절 ①) |
| 문단 | 문단. 문단 안 줄바꿈은 공백 하나, 줄 끝 공백 둘 · `\` 는 줄바꿈 |
| 펜스 코드 · 네 칸 들여쓴 코드 | 코드. 안의 줄 그대로, 언어 표시는 버린다 |
| `>` 인용 | 인용 하나. 안의 문단은 줄바꿈으로 잇고, 문단이 아닌 것(목록 · 코드 등)은 그 글자를 줄로 잇는다 |
| `-` `*` `+` 목록 | 글머리 목록 |
| `1.` `1)` 목록 | 번호 목록. 시작 번호를 지킨다 |
| 목록 항목 아래 들여쓴 블록 | 그 항목의 하위 블록(하위 목록 · 문단 · 코드 · 인용 · 표). 블록 깊이는 32 까지 |
| `- [ ]` · `- [x]` | 체크 항목(끔 · 켬) |
| `---` `***` `___` | 구분선 |
| GFM 표 | 표. 열 정렬을 지키고, 모자란 칸은 빈 칸 · 넘치는 칸은 버린다 |
| 빈 줄 | 블록이 아니다. 빈 여백(`spacer`)을 만드는 문법은 없다 |

### 글자 모양

| 문법 | 모양 |
|---|---|
| `**a**` `__a__` | 굵게 |
| `*a*` `_a_` | 기울임. 인용 안에서는 바로 선 글자 |
| `~~a~~` `~a~` | 취소선 |
| `` `a` `` | 코드. 안의 글자는 원문 그대로 |

굵게 · 기울임 · 취소선은 서로 겹친다. 코드 구간에는 취소선만 붙는다.

### 글자로만 보이는 문법

| 문법 | 보이는 글자 |
|---|---|
| 링크 `[a](u)` · 참조 링크 | `a` (주소는 버린다) |
| 이미지 `![a](u)` | 대체 글 `a` |
| 자동 링크 `<https://x>` · 맨 주소 | 꺾쇠 없는 주소 |
| 인라인 HTML `<T>` · `<br>` | 그 글자 그대로 |
| HTML 블록 | 원문을 코드 블록으로 |
| 수식 `$…$` · `$$…$$` · 형광 `==a==` | 원문 글자 |
| 알림 `> [!NOTE]` | 인용. 머리 표시는 글자로 남는다 |
| 링크 참조 정의 줄 | 보이지 않는다 |
| 이스케이프 `\*` · 엔티티 `&amp;` | 그 글자 |

각주 · 다이어그램 · 코드 색칠은 없다.

## 4. 한도

원문이 512KB(524,288 바이트)를 넘거나 줄 앞 컨테이너(`>` · 목록 표시) 중첩이 32단을 넘으면 앱은 해석하지 않고
노트 전체를 "한도 넘음" 상자로 보인다. 그 노트는 목록에 남고 다른 노트는 그대로다.

## 5. 쓰기 규칙

앱과 GitHub 웹에서 같은 글이 같게 보이도록 지킨다.

1. 제목은 `#` 줄로만 쓴다 — 밑줄 제목(`===` · `---`) 금지. 노트 제목은 앞머리에 있으니 본문에 `#` 로 되풀이하지 않는다.
2. 문단 바로 다음 줄에 `---` 를 두지 않는다. 빈 줄을 두고 쓴다 — 붙이면 문단이 제목이 된다.
3. 굵게 · 기울임의 끝 글자가 문장부호이고 바로 뒤에 글자가 붙으면 모양이 안 먹는다. 문장부호를 밖으로 내거나 공백을 둔다.
   `**"인용"**이다` → `"**인용**"이다` · `**코드(code)**를` → `**코드(code)** 를`
4. 글자로 쓰는 `<` `~` `*` `_` `$` `==` 와 표 안의 `|` 는 백슬래시로 이스케이프한다 —
   `Box\<T>` · `\~10` · `\$5` · `\=\=` · `a \| b`. 코드 구간 · 코드 블록 안은 이스케이프하지 않는다(백슬래시가 그대로 보인다).
   단, 표 칸 안 코드 구간의 `|` 는 이스케이프한다 — `` `a\|b` `` 는 칸을 나누지 않고 `a|b` 로 보인다.
5. 목록 표시(`-` · `*` · `+` · `1.` · `1)`)로 시작하는 줄을 문단의 이어지는 줄로 두지 않는다. 앱은 번호 · 빈 항목과 상관없이
   그 줄에서 문단을 끊는다(CommonMark 와 다르다). 목록은 빈 줄을 두고 시작한다.

## 6. index.json 형태 (생성물)

`gen_index.py` 가 생성한다(직접 편집 금지). **group 키 → 노트 항목 배열**인 JSON 오브젝트:

```jsonc
{
  "android": [
    { "id": "nav3", "title": "…", "date": "2026.06.18",
      "path": "notes/android/nav3.md", "hash": "8970…" },
    …
  ],
  "kotlin": [ … ]
}
```

- 항목 필드: `id` · `title` · `date` · `path`(레포 루트 기준) · `hash`. group 은 상위 키라 항목에 없다.
- `hash` = **노트 파일 raw 바이트의 `sha256`(hex)**. 앱은 이 값을 **비교만** 한다(같으면 skip, 다르면 재fetch).
- 정렬: group 키 오름차순, 그룹 안은 `date` 내림차순 → `id` 오름차순. 출력은 결정적이다.
- 앱은 `path` 의 확장자로 형식을 고른다 — `.md` 는 마크다운, 그 밖은 JSON.

## 7. 노트 추가 · 수정 절차

1. `notes/<group>/<id>.md` 를 이 문서대로 쓰거나 고친다.
2. 커밋한다. pre-commit 훅이 `gen_index.py` 로 `index.json`(+hash)을 다시 만들어 같은 커밋에 넣는다.
   앞머리가 틀리면 커밋이 멈추고 어느 파일이 왜 틀렸는지 말한다. 커밋 전에 `python3 notes/gen_index.py` 로 미리 볼 수 있다.
3. push 해야 반영된다. 앱은 원격의 `notes/index.json` 을 받아 reconcile 한다.

## 8. 옛 JSON 노트 (읽기 호환)

`notes/<group>/<id>.json` 도 앱과 생성기가 읽는다. 새 노트는 `.md` 로 쓴다.
JSON 은 형식 `1` 의 닫힌 집합으로만 읽는다 — 표 · 기울임 · 취소선 · 하위 블록 · 체크 · 시작 번호는 JSON 에 없다.
형식 `1` 의 정본은 `public-repos/notes-kit/SPEC.md` 다.

- 노트 겉틀: `{ "id", "title", "date", "blocks": [...] }`. `id` 는 노트 안 값이고 `.md` 노트와 함께 전역 유일하다.
- 블록 8종: `heading`(`level` 2 · 3, `spans`) · `paragraph`(`spans`) · `code`(`code`) · `quote`(`spans`) ·
  `bulletList` · `orderedList`(`items` = `{ "spans" }` 배열) · `divider` · `spacer`.
- 글자 모양 3종(`style`): `text`(기본, 생략 가능) · `bold` · `code`.
- 생성기가 닫힌 집합 밖(모르는 `type` · `style` · 필수 필드 누락)을 거부한다. 훅을 거치지 않고 올라간 노트는
  앱이 그 블록만 `원문 보기` 상자로, 모르는 `style` 은 일반 글자로 보인다.
