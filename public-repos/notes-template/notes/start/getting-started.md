## 앱에 연결하기

이 노트는 템플릿에 들어 있는 예시입니다. 지금 보고 있다면 **저장소 연결이 끝난 것**입니다.

1. GitHub 에서 이 템플릿으로 저장소를 만듭니다.
2. 저장소 주소를 복사합니다.
3. 앱의 **저장소 주소** 칸에 붙여 넣고 **연결**을 누릅니다.

## 노트 추가하기

노트 하나는 파일 하나입니다. 위치는 `notes/<그룹>/<id>.md` 이고, 폴더 이름이 그룹이 됩니다.
파일 맨 위 앞머리에 제목과 날짜를 적고, 그 아래에 마크다운으로 본문을 씁니다.

```markdown
---
title: 첫 노트
date: 2026.10.06
---
## 소제목

본문을 씁니다.
```

- **웹**: GitHub 에서 파일을 직접 추가합니다.
- **로컬**: 저장소를 내려받아 편집하고 올립니다.
- **플러그인**: 스킬로 노트를 저장합니다.

> 올리고 나면 저장소의 작업이 목록 파일을 알아서 다시 만듭니다. 앱에서 새로고침하면 새 노트가 보입니다.

---

노트 형식은 **노트 형식 둘러보기** 노트에서 모양마다 하나씩 보여 드립니다.
