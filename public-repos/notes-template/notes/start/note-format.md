## 글

문단 안에서 **굵게** · *기울임* · ~~취소선~~ · `인라인 코드` 를 쓸 수 있습니다. 모양은 서로 겹칠 수도 있습니다.

### 인용과 코드

> 인용은 이렇게 보입니다.

```kotlin
fun greet(name: String) = println("안녕하세요, " + name)
```

3. 번호 목록은 시작 번호를 지킵니다.
4. 그래서 셋째부터 셀 수 있습니다.

- [x] 끝낸 일
- [ ] 남은 일

## 표

| 모양 | 문법 | 쓰임 |
|:---|:---:|---:|
| 굵게 | `**a**` | 강조 |
| 기울임 | `*a*` | 낱말 |
| 취소선 | `~~a~~` | 지운 말 |

---

새 노트도 이 두 노트처럼 앞머리 두 줄과 마크다운 본문으로 씁니다. 앱이 그리지 못하는 문법은 글자로 보이니 규격의 문법 표를 따릅니다.
