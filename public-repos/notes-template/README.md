# 내 노트 저장소

GitHub 저장소에 노트를 올리면 노트 앱이 읽어 가는 **노트 저장소 템플릿**입니다.
이 템플릿으로 저장소를 만들면 예시 노트와 이미 만들어진 노트 목록(`notes/index.json`)이 함께 들어 있어, 만들자마자 앱에 연결할 수 있습니다.

## 시작하기

1. 저장소를 만듭니다. 앱의 연결 화면에서 **저장소 만들기**를 누르면 이 템플릿의 만들기 화면이 바로 열립니다. 이 페이지 위쪽의 `Use this template` → `Create a new repository` 로 직접 만들어도 됩니다. 이름과 공개 여부를 정합니다.
2. 만들어진 저장소의 주소를 복사합니다. 예: `github.com/내계정/내저장소`
3. 앱에서 **저장소 주소** 칸에 붙여 넣고 **연결**을 누릅니다.
4. 예시 노트가 홈에 보이면 끝입니다.

비공개로 만들었다면 아래 [비공개로 만들었다면](#비공개로-만들었다면)을 먼저 봅니다.

## 노트 추가

노트 하나는 파일 하나이고 `notes/<그룹>/<id>.json` 에 둡니다. 폴더 이름이 그룹입니다. 예시는 `notes/start/` 에 있습니다.
어느 길로 올리든 `notes/<그룹>/<id>.json` 만 올립니다. `notes/index.json` 은 올린 뒤 저장소의 작업(Actions)이 알아서 다시 만들어 같은 브랜치에 커밋하므로 손대지 않습니다.

- **웹**: 저장소 페이지에서 `Add file` → `Create new file` 로 `notes/<그룹>/<id>.json` 을 만들고 커밋합니다.
- **로컬**: 저장소를 내려받아 편집하고 push 합니다. 작업이 `index.json` 을 커밋하기 때문에 **로컬에서 이어 쓰기 전에는 `git pull` 을 한 번** 합니다.
- **플러그인**: 도구 레포(`https://github.com/<KIT_REPO>`)의 안내대로 `mynote-notes` 플러그인을 설치하고 `write-note` 스킬로 저장합니다.

올린 뒤 앱에서 새로고침하면 새 노트가 보입니다.

## 비공개로 만들었다면

비공개 저장소는 앱이 읽을 수 있도록 **읽기 전용 토큰**이 필요합니다. 연결할 때 앱이 `토큰이 필요합니다` 화면에서 만드는 법을 안내합니다.
종류는 세분화된 토큰, 범위는 이 저장소 하나만, 권한은 콘텐츠 읽기 전용입니다. 토큰은 앱에만 입력하고 저장소에는 적지 않습니다.

## 형식

노트는 닫힌 규격을 따릅니다. 블록 종류 · 글자 모양 · 목록 모양은 규격 문서에 있습니다.

- 규격: `https://github.com/<KIT_REPO>/blob/v1/SPEC.md`
- 지원 앱 형식: `1` (저장소 루트의 `.mynote-format` 한 줄)

규격에 없는 블록이나 글자 모양을 쓰면 작업이 실패하고 목록은 그대로 남습니다.

## 문제 해결

- **Actions 탭에 빨간 표시가 있습니다.** 실패한 작업을 열면 `파일 경로: 이유` 한 줄이 나옵니다. 그 파일을 규격대로 고쳐 다시 올립니다. 실패하는 동안 `index.json` 은 직전 그대로라 앱은 직전 목록을 계속 보여 줍니다.
- **앱에 "이 저장소에는 노트 목록이 없습니다" 가 뜹니다.** 주소가 이 저장소가 맞는지, `notes/index.json` 이 있는지 확인합니다. 템플릿으로 만든 저장소에는 처음부터 들어 있습니다. 템플릿으로 방금 만들었다면 잠시 뒤 다시 연결합니다.
- **작업이 `index.json` 을 올리지 못하고 실패합니다.** 조직 정책이 Actions 의 쓰기 권한을 막았거나 기본 브랜치에 브랜치 보호 규칙이 있으면 봇이 `index.json` 을 올리지 못합니다. 설정에서 쓰기 권한을 허용하거나 봇의 push 를 허용해야 합니다.
- **새 형식이 나와서 Action 버전을 올려야 합니다.** `.github/workflows` 의 파일에서 `@v1` 의 숫자만 바꿉니다.
