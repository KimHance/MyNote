# check-notes

저장소의 노트가 규격(`${CLAUDE_PLUGIN_ROOT}/SPEC.md`)에 맞는지 검사 도구로 확인하고, 틀린 곳을 알아듣게 풀어 말합니다. **이 스킬은 파일을 고치지 않습니다.** 고칠 방법을 제안만 하고, 고치는 일은 사용자가 시키면 `write-note` 로 합니다.

## 검사

저장소 루트에서 실행합니다.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/note_tool.py" check
```

- 노트 폴더가 `notes` 가 아니면 `--notes-dir <폴더>` 를 붙입니다.
- 통과하면 `✓ 노트 N개가 규격에 맞습니다` 한 줄이 나옵니다.
- 실패하면 오류가 **`파일 경로: 이유`** 한 줄씩 나옵니다. 이 줄 형식을 그대로 받아서 씁니다.

## 도구가 보는 것

- 마크다운 노트(`.md`)는 **앞머리만** 봅니다. 경계 줄 `---` 두 개, 키 `title` · `date` 둘, 날짜 모양 `YYYY.MM.DD`, 빈 값 · 같은 키 두 번 · 모르는 키, UTF-8 인지를 봅니다.
- **도구는 마크다운 본문을 보지 않습니다.** 그래서 본문에 앱이 그리지 못하는 문법이 있거나 노트가 한도를 넘어도 검사는 통과합니다.
- 옛 JSON 노트(`.json`)는 형식 `1` 의 닫힌 집합(블록 종류 · 인라인 스타일 · 헤딩 레벨 · 필수 키)을 봅니다.
- 두 형식을 통틀어 `id` 가 겹치거나, 확장자가 `.MD` 처럼 대소문자만 다르면 실패합니다.

## 결과 풀이

오류 줄마다 다음 네 가지를 말합니다.

1. **어느 파일** — 줄 앞의 파일 경로
2. **무엇이 틀렸나** — 줄 뒤의 이유를 쉬운 말로. 앞머리 오류는 무엇이 빠졌거나 어긋났는지 그대로 풀어 줍니다(예: "앞머리에 'date' 가 없습니다" → 날짜 줄을 더해야 합니다).
3. **규격의 어느 절을 보면 되나** — `${CLAUDE_PLUGIN_ROOT}/SPEC.md` 의 해당 절
   - 마크다운 노트의 앞머리 오류: `## 앞머리` · `### 앞머리 키`
   - 확장자 · `id` 겹침: `## 폴더 배치`
   - 옛 JSON 노트: `## 옛 JSON 노트 (형식 1)` 과 그 아래 `### 블록 종류` · `### 인라인 스타일` · `### 헤딩 레벨`
   - `.mynote-format` 오류: `## 형식 판`
4. **고친 예** — 마크다운 노트면 고친 앞머리 조각, 옛 JSON 노트면 고친 JSON 조각(또는 `.md` 로 옮긴 모양)

```markdown
---
title: 코루틴 디스패처 고르기
date: 2026.01.01
---
```

여러 파일이 틀렸으면 파일별로 묶어 보여 줍니다. 통과했으면 통과했다고만 말하고 더 만들어 내지 않습니다.

## 앱에서 노트가 이상하게 보이면

검사가 통과했는데 앱에서 글자가 그대로 보이거나 노트가 상자 하나로 보이면, 도구가 보지 않는 본문 탓입니다. 노트 본문을 규격의 `### 글자로만 보이는 문법` · `## 한도` 절과 눈으로 대조해 어느 줄이 걸리는지 알려 줍니다. 모든 노트가 상자로 보이면 앱이 마크다운을 읽지 못하는 옛 판일 수 있다고 알려 줍니다.

## 파이썬이 없으면

`python3` 가 없거나 도구가 안 돌면, `${CLAUDE_PLUGIN_ROOT}/SPEC.md` 를 읽고 노트를 눈으로 대조합니다. 마크다운 노트는 첫 줄과 앞머리 끝 줄이 정확히 `---` 인지, 키가 `title` · `date` 둘뿐인지, 날짜가 `YYYY.MM.DD` 인지 봅니다. 옛 JSON 노트는 최상위 네 키(`id` · `title` · `date` · `blocks`), 블록 `type` 이 닫힌 집합 안인지, `spans` 가 비어 있지 않은지, `style` 과 헤딩 `level` 이 집합 안인지 봅니다. 도구로 확인하지 못했다고 말해 줍니다.

## 하지 않는 것

- 노트 파일을 고치지 않습니다. `index.json` 도 만들지 않습니다.
- 도구가 통과시킨 노트를 규격 밖이라고 우기지 않습니다. 본문 문법은 "앱에서 이렇게 보일 수 있다" 고만 말합니다.
